# 8-bit Tri-state Buffer

8비트 입력을 Enable 신호에 따라 출력으로 전달하는 버스용 버퍼입니다.

## 핀

| 핀 | 방향 | 의미 |
| --- | --- | --- |
| A0~A7 | 입력 | 8비트 데이터 입력 |
| EN | 입력 | 출력 활성화 |
| Q0~Q7 | 출력 | 8비트 데이터 출력 |

## 동작

| EN | Q0~Q7 |
| --- | --- |
| 0 | `00000000` |
| 1 | `A0~A7` |

## 주의

현재 시뮬레이터에는 실제 High-Z 상태가 없으므로, 비활성화 상태는 모든 출력 LOW로 처리됩니다. OR 방식 버스 집계와 함께 쓰도록 설계되어 있습니다.
