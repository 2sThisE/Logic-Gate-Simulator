# 8-bit 3-Port Bus Aggregator

세 개의 8비트 입력 포트를 OR 연산으로 합쳐 하나의 8비트 출력으로 내보냅니다.

## 핀

| 핀 | 방향 | 의미 |
| --- | --- | --- |
| A0~A7 | 입력 | 첫 번째 8비트 입력 |
| B0~B7 | 입력 | 두 번째 8비트 입력 |
| C0~C7 | 입력 | 세 번째 8비트 입력 |
| Q0~Q7 | 출력 | OR로 합쳐진 8비트 출력 |

## 수식

```text
Q = A | B | C
```

## 사용 방식

Tri-state Buffer가 비활성화될 때 `00000000`을 내보내므로, 활성화된 소스만 버스 결과에 남도록 조합할 수 있습니다.
