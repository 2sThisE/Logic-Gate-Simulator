# Clock 7-Segment (4-Digit)

12핀 멀티플렉싱 방식의 4자리 7-segment 표시 장치입니다.

## 핀

| 핀 | 방향 | 의미 |
| --- | --- | --- |
| 0~7 | 입력 | 세그먼트 라인 `a, b, c, d, e, f, g, dp` |
| 8~11 | 입력 | 자리 선택 라인 |

## 동작

시각화 전용 노드입니다. 입력 핀 조합에 따라 선택된 자리와 세그먼트가 화면에 표시됩니다.

## 사용 방식

디코더나 카운터 회로에서 세그먼트 라인과 자리 선택 라인을 주기적으로 바꿔주면 4자리 표시를 구성할 수 있습니다.
