# 7-Segment Display

8개 입력으로 7-segment 표시 상태를 그리는 시각화 전용 모드 컴포넌트입니다.

## 핀

| 핀 | 방향 | 의미 |
| --- | --- | --- |
| a | 입력 | 상단 세그먼트 |
| b | 입력 | 우상단 세그먼트 |
| c | 입력 | 우하단 세그먼트 |
| d | 입력 | 하단 세그먼트 |
| e | 입력 | 좌하단 세그먼트 |
| f | 입력 | 좌상단 세그먼트 |
| g | 입력 | 중앙 세그먼트 |
| dp | 입력 | 소수점 |

## 동작

계산 출력은 없고, 입력 비트의 HIGH/LOW 상태를 화면 표시로만 사용합니다.
