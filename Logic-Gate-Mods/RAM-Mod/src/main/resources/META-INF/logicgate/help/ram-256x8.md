# 256x8 RAM

256개 주소에 각각 8비트 값을 저장하는 메모리 모드 컴포넌트입니다.

## 핀

| 핀 | 방향 | 의미 |
| --- | --- | --- |
| A0~A7 | 입력 | 8비트 주소 |
| D0~D7 | 입력 | 저장할 8비트 데이터 |
| WE | 입력 | Write Enable |
| OE | 입력 | Output Enable |
| Q0~Q7 | 출력 | 읽은 8비트 데이터 |

## 쓰기

`WE`가 LOW에서 HIGH로 바뀌는 상승 에지에서 현재 주소에 `D0~D7` 값이 저장됩니다.

```text
if WE rises:
  memory[address] = dataIn
```

## 읽기

| OE | Q0~Q7 |
| --- | --- |
| 0 | `00000000` |
| 1 | `memory[address]` |

## 주의

현재 구현은 실제 High-Z 출력을 갖지 않습니다. `OE=0`일 때는 버스 조합을 위해 모든 출력이 LOW가 됩니다.
